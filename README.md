# math2word – המרת שאלוני מתמטיקה (PDF / תמונה) ל־Word בר עריכה

המערכת מקבלת קובץ PDF או תמונה של שאלה/שאלון במתמטיקה ומפיקה קובץ Word (`.docx`) שאפשר לערוך:

* **עברית תקנית מימין לשמאל**: כל פסקה מוגדרת RTL, ומספור (1. / א. / (1) / I.) עם הזחה תלויה כמו במקור.
* **מתמטיקה משמאל לימין כמשוואות Word אמיתיות** (OMML, עורך המשוואות של Word). הן לא תמונות ולא טקסט.
  הנוסחאות מתומללות ל־LaTeX ומומרות למשוואות Word באמצעות pandoc.
* **שבירת שורות כמו במקור**: כל שורה מודפסת במקור היא שורה אחת ב־Word (מעבר שורה ידני). המערכת מעריכה
  את רוחב כל שורה, וכשצריך היא מקטינה מעט את הסרטוט או את הגופן כדי ששורה לא תישבר.
* **סרטוטים, גרפים ותרשימים**: נחתכים מהמקור ברזולוציה 300 DPI. ב־PDF וקטורי גבולות החיתוך "נצמדים"
  לקווי הסרטוט ולתוויות שלו (שמות נקודות, צירים). סרטוט שמופיע ליד הטקסט נשאר לידו (טבלה בלי גבולות).
* כותרות עליונות ותחתונות, "המשך בעמוד", ברקודים, מסגרות, דפי טיוטה ומשבצות לתשובה מושמטים.

## איך זה עובד

```
PDF / תמונה ──► רינדור עמודים (PyMuPDF)
            ──► Claude (ראייה + structured outputs) ──► JSON לכל עמוד:
                   פסקאות › שורות › קטעי [טקסט | LaTeX], סרטוטים + מיקום
            ──► חיתוך סרטוטים (הצמדה לקווים וקטוריים)
            ──► LaTeX ► OMML (pandoc)
            ──► בניית DOCX בכיוון RTL (python-docx)
```

הסכמה של ה־JSON נמצאת ב־`math2word/schema.py`, וההנחיות למודל ב־`math2word/prompts.py`.

## התקנה

```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY=sk-ant-...
```

## שימוש

שורת פקודה:

```bash
python -m math2word questionnaire.pdf -o questionnaire.docx          # כל השאלון
python -m math2word questionnaire.pdf -p 4-7,10 -o q.docx            # עמודים נבחרים
python -m math2word photo_of_question.jpg -o q.docx                  # תמונה/סריקה
python -m math2word q.pdf --save-json q.json                         # שמירת התמלול
python -m math2word q.pdf -p 3 --from-json q.json -o q.docx          # בנייה מחדש בלי קריאה למודל
```

אפשרויות: `--font` (ברירת מחדל David), `--size` (11), `--no-page-breaks`, `--all-pages`,
`--effort` (`high`; עם `xhigh`/`max` הדיוק עולה וגם הזמן והעלות).
תמלולי עמודים נשמרים ב־`.math2word_cache/`, ולכן הרצה חוזרת על אותו קובץ לא עולה כסף.

ממשק ווב (העלאת קובץ והורדת Word):

```bash
python web/app.py      # http://localhost:5000
```

## דוגמאות

בתיקייה `examples/` יש שני עמודים משאלוני הדוגמה, שתומללו ידנית בדיוק בפורמט שהמודל מחזיר, ואת קובצי ה־Word
שנבנו מהם:

* `demo_new1_p3.docx`: שאלון 35571, עמוד 3 (גרף פונקציה + ערך מוחלט, גאומטריה עם סרטוט).
* `demo_q26_p10.docx`: שאלון 35372, עמוד 10 (פרבולה עם סרטוט, סעיפים משנה).

```bash
python examples/make_demo_json.py
python -m math2word <questionnaire_new_1.pdf> -p 3 --from-json examples/demo_new1_p3.json -o out.docx
```

## מגבלות ידועות

* הסרטוטים נכנסים כתמונות PNG באיכות גבוהה. אפשר להזיז ולשנות את גודלם, אבל לא לערוך את הקווים עצמם.
* הדיוק תלוי באיכות הסריקה. ב־PDF מקורי (כמו השאלונים של משרד החינוך) הוא גבוה מאוד, ובצילום טלפון מומלץ
  לצלם ישר ובתאורה טובה.
* לפני הפצה כדאי לעבור על המסמך. אם המרה של נוסחה ל־OMML נכשלת, ה־LaTeX שלה מופיע כטקסט נטוי
  כדי שיהיה קל למצוא אותה ולתקן.
